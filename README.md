# JobMon

JobMon is a personal job-search management application for organizing opportunities, tracking applications, and identifying items that need attention.

This repository contains the public information site and privacy policy for the project. The application itself is private.

## Project overview

JobMon brings job postings, application status, and related communications into one workflow. Its evaluation process helps surface relevant roles for review. I have tested results against real postings, identified errors involving seniority and clearance requirements, and proposed improvements to the scoring criteria.

## This repository

- `index.html` — project overview and contact information
- `privacy.html` — privacy policy
- `CNAME` — custom domain configuration

JobMon is a personal project developed with AI assistance. The live site is available at [jobmonapp.com](https://www.jobmonapp.com/).
